Memeriksa layanan AI...

Smart Proposal & RAB Architect

Isi data kegiatan. AI menyusun latar belakang bernuansa Bali, rundown, dan RAB yang totalnya tepat sama dengan pagu.

AI Budget & Feasibility Auditor

Tempel rancangan anggaran manual Anda. AI menilai kelayakan, efisiensi, dan item krusial yang terlewat.

Smart Correspondence & LPJ Generator

Hasilkan draf surat resmi dan ringkasan LPJ. Data yang belum Anda isi akan ditandai dengan placeholder [ ].

Dashboard Arsip & Analitik

Semua proposal, audit, dan dokumen tersimpan otomatis di database SQLite.

AI & Technology Disclosure

AI di dalam aplikasi

Teks proposal, rundown, item RAB, hasil audit, surat, dan LPJ dihasilkan oleh Google Gemini API (model gemini-3.1-flash-lite) yang dipanggil dari backend Flask. Perhitungan total RAB dikunci oleh kode Python agar tepat sesuai pagu, bukan oleh AI.

Teknologi

Frontend HTML5, Tailwind CSS (CDN), dan Vanilla JavaScript. Backend Python Flask. Database SQLite. API Key disimpan di environment variable server dan tidak pernah ada di kode sumber atau di browser.

Bantuan AI dalam pengembangan

Kerangka kode aplikasi ini disusun dengan bantuan asisten AI, kemudian ditinjau, diuji, dan disesuaikan oleh tim pengembang.

Batasan penggunaan

Seluruh keluaran AI berupa draf. Harga, nominal, dan isi surat wajib diperiksa dan disahkan oleh pengurus organisasi dan pembina sebelum digunakan secara resmi.
